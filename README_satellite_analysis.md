# 卫星影像分割测试系统

基于SAM2 (Segment Anything Model 2) 的卫星影像自动分割系统，用于获得原始的图像分割结果，为后续语义识别奠定基础。

## 功能特点

- 🛰️ **支持TIF格式**：专门优化处理卫星影像TIF文件，支持多波段数据自动转换为RGB
- 🎯 **智能分割**：基于SAM2的自动掩码生成，无需手动标注
- 🎨 **纯色分区**：生成与原影像严格套合的纯色分区mask文件（PNG格式）
- 🏷️ **颜色映射**：自动生成颜色映射表，记录分区ID与颜色的对应关系
- 📊 **统计分析**：提供详细的分割区域统计信息
- 🖼️ **可视化输出**：生成分割结果可视化图像（原图+半透明彩色掩码）
- 📋 **报告生成**：自动生成JSON统计文件和文本报告
- 🚀 **内存优化**：支持大图像处理，包含内存不足时的自动缩放和错误恢复机制

## 环境要求

- Python 3.8+
- PyTorch (支持CUDA加速)
- 已安装的SAM2项目依赖

## 安装说明

1. 确保SAM2项目环境已正确配置
2. 检查`config.py`中的模型路径设置：

```python
MODEL = {

```

## 使用方法

### 基本用法

```bash
python satellite_segmentation_test.py --input your_satellite_image.tif --output ./results
```

### 详细参数说明

```bash
python satellite_segmentation_test.py \
    --input /path/to/satellite_image.tif \    # 输入影像路径
    --output ./output \                        # 输出目录
    --model large \                           # 模型类型 (large/base/small/tiny)
    --device auto                             # 计算设备 (auto/cuda/cpu/mps)
```

### 参数详解

- `--input, -i`: 输入卫星影像路径（必需）
  - 支持格式：TIF, TIFF, JPG, PNG等
  - 推荐使用TIF格式的卫星影像
  
- `--output, -o`: 输出目录（默认：./output）
  - 自动创建目录结构
  - 保存所有分析结果
  
- `--model, -m`: 模型类型（默认：large）
  - 支持：large, base, small, tiny
  - 对应config.py中的模型配置
  - large模型精度最高但速度较慢，tiny模型速度最快但精度较低
  
- `--device, -d`: 计算设备（默认：auto）
  - auto: 自动选择最佳设备（推荐）
  - cuda: 强制使用GPU
  - cpu: 使用CPU计算
  - mps: Apple Silicon Mac使用MPS加速

## 输出文件说明

运行完成后，会在输出目录生成以下文件：

```
output/
├── [filename]_original.jpg              # 原始影像（JPG格式）
├── [filename]_segmentation.jpg          # 分割结果可视化（原图+半透明彩色掩码）
├── [filename]_mask.png                  # 纯色分区mask文件（PNG格式）
├── [filename]_mask_color_mapping.json   # 颜色映射表
├── [filename]_statistics.json          # 统计数据(JSON格式)
└── [filename]_report.txt               # 详细分析报告
```

### 文件内容说明

1. **原始影像** (`_original.jpg`): 输入影像的JPG格式副本，用于对比查看
2. **分割可视化** (`_segmentation.jpg`): 原图叠加半透明彩色掩码，直观显示分割效果
3. **纯色分区mask** (`_mask.png`): **核心输出文件**，每个分区使用唯一的纯色表示
   - PNG格式无损保存，像素与原影像严格套合
   - 背景区域为黑色(0,0,0)，每个分区使用不同的RGB颜色
   - 可用于后续的语义识别和地物分类分析
4. **颜色映射表** (`_mask_color_mapping.json`): 记录分区ID与RGB颜色的对应关系
   - 包含总分区数量、各分区颜色值等信息
   - 便于程序化处理mask文件
5. **统计数据** (`_statistics.json`): 包含分割区域的详细统计信息
6. **分析报告** (`_report.txt`): 人类可读的详细报告，包含处理流程和结果说明

## 核心功能详解

### 1. 智能分割功能
- **自动分割**：基于SAM2的点网格采样和掩码生成，自动识别图像中的不同区域
- **内存优化**：支持大图像处理，内存不足时自动缩放图像并将结果转换回原始尺寸
- **错误恢复**：多次尝试机制，确保在不同硬件条件下都能成功处理

### 2. 纯色分区mask生成
- **精确对应**：生成与原影像像素完全对应的纯色分区文件
- **唯一标识**：每个分区使用HSV色彩空间均匀分布的唯一RGB颜色
- **无损保存**：PNG格式保存，确保像素精度不丢失
- **程序友好**：配套颜色映射JSON文件，便于后续程序化处理

### 3. 完整输出体系
- **可视化展示**：原图叠加半透明掩码，直观查看分割效果
- **统计分析**：详细的区域面积、数量等统计信息
- **标准化报告**：结构化的JSON数据和人类可读的文本报告

这为后续的语义识别、地物分类和矢量化处理奠定了坚实基础。

### 参数调优

代码中已针对卫星影像优化了关键参数，如需进一步调整：

```python
# 在SatelliteImageProcessor类的load_model方法中
self.mask_generator = SAM2AutomaticMaskGenerator(
    model=self.sam2_model,
    points_per_side=16,        # 当前为16，降低可提高速度，提高可增加精度
    points_per_batch=32,       # 当前为32，根据显存大小调整
    pred_iou_thresh=0.75,      # 当前为0.75，提高可减少低质量掩码
    stability_score_thresh=0.85, # 当前为0.85，提高可减少不稳定掩码
    min_mask_region_area=200,  # 当前为200，提高可过滤小区域
    use_m2m=False,             # 禁用以节省内存
    crop_n_layers=0            # 禁用裁剪层以节省内存
)
```

## 常见问题

### Q: 模型加载失败
A: 检查config.py中的模型路径是否正确，确保.pt文件存在

### Q: CUDA内存不足
A: 尝试降低points_per_side和points_per_batch参数，或使用CPU模式

### Q: TIF文件读取错误
A: 确保TIF文件格式正确，系统会自动处理多波段数据并转换为RGB格式

### Q: 图像过大导致内存不足
A: 系统会自动缩放图像，结果会转换回原始尺寸，确保精度不丢失

### Q: 分割区域过多或过少
A: 可调整min_mask_region_area参数过滤小区域，或调整points_per_side改变分割密度

## 技术说明

### 算法流程

1. **影像预处理**: 
   - 加载TIF文件，自动处理16位、浮点数等多种数据类型
   - 多波段数据自动选择前三个波段组成RGB，单波段转为灰度
   - 大图像自动缩放到适合SAM2处理的尺寸（最大1024像素）

2. **智能分割**: 
   - 使用SAM2在图像上采样16x16密集点网格
   - 为每个点生成高质量分割掩码，使用NMS去重
   - 内存不足时自动进一步缩放并重试，最多尝试3次

3. **结果处理**:
   - 掩码坐标自动转换回原始图像尺寸，确保像素精确对应
   - 生成HSV色彩空间均匀分布的唯一RGB颜色标识
   - 创建纯色分区mask和颜色映射JSON文件

4. **多格式输出**: 
   - 可视化图像、统计数据、详细报告一应俱全
   - 所有输出文件与原影像严格套合

### 关键技术特性

- **内存优化**: 自适应图像尺寸调整，支持大图像处理
- **精度保证**: 所有坐标变换都确保回到原始像素精度  
- **错误恢复**: 多重尝试机制和内存管理
- **标准化输出**: JSON格式数据便于后续程序化处理
